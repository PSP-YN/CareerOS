PRIVACY NOTICE · DRAFT FOR PRODUCT LAUNCH

Privacy Policy

Last updated: 31 October 2026. This draft describes the current product design and must be reviewed for the operator's legal identity, jurisdiction and final vendors before commercial launch.

Information you provide

CareerOS may process your target role, skills, project descriptions, learning progress, resume contact and education details, experience and portfolio links, interview practice answers and job application notes.

Guest mode

Guest workspace data is stored in local browser storage on the device you use. Clearing browser storage or changing devices can remove access to this data.

Signed-in workspaces

When Google OAuth is enabled and the user signs in, account workspace data is stored in Supabase. Row Level Security restricts workspace access to the authenticated account that owns it. Signing in merges existing guest and cloud records rather than blindly replacing the guest workspace.

AI coaching and provider choices

AI reviews are optional and require a separate user action and consent. CareerOS currently offers up to two hosted Gemini reviews per authenticated account per day, subject to provider availability and quota. The hosted pilot uses Google's unpaid Gemini API tier. Under Google's current terms, Google may use submitted content and responses to improve its products and services, and human reviewers may process them. Do not submit personal, sensitive, confidential or proprietary information to this hosted free tier. The app should only be used with appropriately generalized, non-identifying context for these free reviews. Review Google's Gemini API terms before use. Users can instead configure their own Gemini API key or an OpenAI-compatible model endpoint in AI settings. BYOK keys are sent from the browser directly to the configured provider, are not uploaded to CareerOS's server or stored in the CareerOS account, and may be held in browser storage if the user chooses. Browser storage is not a secure vault. The selected provider receives review context under its own terms. Avoid sharing credentials, government identifiers, confidential employer data or information you do not have permission to disclose.

Payments

Paid checkout is not active in this release. If subscriptions are enabled, payment credentials and card details should be handled by the payment provider; CareerOS should store only subscription identifiers, plan and status metadata required to provide the service.

Advertising and analytics

Advertising is not active by default. If advertising or analytics is enabled later, the operator must update this notice, implement legally appropriate consent controls and explain third-party processing before collecting related data.

Retention and deletion

Guest data remains in browser storage until removed by the user or browser. Signed-in users can request account deletion from the workspace account controls. Deletion requires a recently issued sign-in session, an explicit confirmation phrase and the server-side Supabase service key. Deleting the account removes the Supabase user and related database rows through cascading foreign keys. A browser-local guest copy is not deleted automatically; users should export data before deletion and clear local browser storage separately if they want that copy removed. This flow requires production end-to-end verification after server keys and Google OAuth are configured. Contact the operator through the published support channel once one is established.

Security

CareerOS uses HTTPS, server-side secrets and database row policies in its planned signed-in architecture. No internet service can promise absolute security. Do not upload information you are not authorized to share.

Changes

This notice must be updated when data flows, processors, advertising, billing or legal operator details change.
