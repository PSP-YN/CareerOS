# SEO, AEO and GEO implementation

## Technical SEO
- Canonical HTTPS URLs use https://careeros-intelligence.vercel.app.
- Public pages are in sitemap.xml. robots.txt allows public pages and disallows the app/API.
- Open Graph and Twitter metadata are present on the home page.
- SoftwareApplication, Organization, WebSite and FAQPage JSON-LD are included where relevant.
- App workspace is marked noindex because it is a signed-in utility, not search landing content.
- Responsive layout, semantic headings, descriptive page titles and internal links are implemented.

## Answer Engine Optimization (AEO)
- Home page explains what CareerOS does in a direct answer.
- FAQ content uses visible question/answer pairs and FAQPage structured data.
- Pricing, privacy, about and guide pages have distinct canonical URLs.
- llms.txt states product facts and explicitly lists claims that should not be made.

## Generative Engine Optimization (GEO)
- Keep one consistent product name, description and canonical domain across website, repository, social profiles and business listings.
- Publish original, useful, evidence-led career guides. Cite primary sources for claims about job-market trends, salaries, certifications and hiring.
- Add author/reviewer identity and editorial review dates to future guides; do not fabricate experts or endorsements.
- Keep structured data consistent with visible page content. Do not add ratings, reviews, awards, locations or prices that are not real.
- Maintain a public changelog and a clear About page when the product's legal operator is finalized.

## Search engine submission
1. Verify domain ownership in Google Search Console.
2. Submit https://careeros-intelligence.vercel.app/sitemap.xml.
3. Monitor indexing, Core Web Vitals and search queries.
4. Verify Bing Webmaster Tools and submit the same sitemap.
5. Check canonical, robots, sitemap and structured data after each release.

SEO/AEO/GEO are discoverability practices, not ranking guarantees. Search and answer-engine inclusion cannot be guaranteed.
