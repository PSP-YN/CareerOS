# Three-minute demo

1. Open the overview and explain the problem: career changers need a credible path, not a generic list of courses.
2. Set a target role and timeline in Profile.
3. Adjust a few skill levels and show the skill-gap ranking.
4. Paste a real job description you are allowed to use. Show extracted keywords and the resulting skill gaps. Explain that extraction is local and bounded, not scraping.
5. Open Roadmap, prioritize the largest gap, and mark a milestone complete.
6. In Interview Lab, answer one question with a concrete action and measurable outcome. Show the deterministic feedback rubric.
7. If Gemini is configured, tick the consent box and request additional AI feedback. Explain that the answer is sent to the server-side Gemini endpoint only after opt-in.
8. Add an application and show the pipeline.

## Claims to avoid
- Do not call the readiness score a hiring probability.
- Do not claim live job-market data or job-board scraping.
- Do not claim cloud sync, user accounts, or production-grade security.
- Do not claim Gemini is active unless the deployed environment has a valid key and the endpoint has been tested.
