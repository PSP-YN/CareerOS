# Security Policy

## Supported versions

Security fixes are targeted at the current default branch unless the project documents a separate supported release.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in public issues or pull requests.

Use GitHub private vulnerability reporting if enabled for this repository:
https://github.com/PSP-YN/CareerOS/security/advisories/new

If private reporting is unavailable, contact the maintainer privately through GitHub. Include the affected version or commit, impact, reproduction steps, and a minimal proof of concept. Do not include real personal data or live credentials.

## Response

The maintainer will review the report, validate the issue, and coordinate a fix and disclosure where practical. No response-time SLA is promised.

## Handling secrets

Never commit API keys, passwords, private keys, tokens, production database dumps, or personal data. Revoke and rotate any credential that may have been exposed. Report suspected exposures privately.
