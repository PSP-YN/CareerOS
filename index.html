ANSWERS BEFORE YOU START

Frequently asked questions

What is CareerOS?

CareerOS is a career planning workspace that connects a target role, skill gap assessment, learning milestones, interview practice and job application tracking.

Does CareerOS guarantee a job or interview?

No. CareerOS is a planning and practice tool. It does not predict hiring outcomes, guarantee placement or represent any employer.

How does skill gap analysis work?

You rate your current capability and compare it with target levels. The prioritization is a directional aid, not an independently validated labour-market assessment.

Does CareerOS use live job-market data?

The current version analyses job description text that you paste into the workspace. It does not scrape job boards or claim to provide live salary or vacancy statistics.

Can I use CareerOS for free?

Yes. The Explore plan is free. The proposed paid plans add cloud sync and expanded coaching capabilities when paid billing is launched.

How is my information stored?

Guest mode stores workspace data in your browser. When Supabase authentication and database configuration are enabled, signed-in workspaces can sync to a private row protected by Row Level Security.
